**The single most useful entity in this project.**

Japan's largest game developers' conference, run by CESA. CEDEC 2026 ran **22–24 July in
Yokohama**, with generative AI prominent throughout — sessions on video-plus-generative-AI QA,
LLM-assisted development, Square Enix on zero-to-prototype generative workflows, and a
lightning track on AI playtesting and AI debugging.

**Crucially, the 2026 programme included a session on mathematical optimisation and machine
learning for multi-player imperfect-information game AI.** Quantitative, game-theoretic
material is in scope — this is not a conference only about art pipelines.

**Why it matters more than any client.** CEDEC runs an **open session submission process**.
A talk is simultaneously the missing track record, a credential a Japanese studio recognises,
and direct access to the exact audience — obtained by writing a good proposal rather than by
selling to anyone. Every other project in this repo lacked a channel like this.
