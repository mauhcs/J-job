**The one route in this repo where discovery is decided on merit rather than relationships.**

CEDEC is Japan's largest game developers' conference, run by CESA, with an open session
submission process. The 2026 programme included mathematical optimisation and ML for
multi-player imperfect-information game AI, so quantitative material is accepted.

1. Find the **submission window, format and language requirements** for the next edition.
2. Read the last two programmes for what is already covered — avoid QA automation, which
   Square Enix and the Matsuo lab own.
3. Propose something only this background produces. Strongest candidates:
   - **"What market surveillance knows about cheat detection"** — adversarial sequence
     detection, false-positive economics, an adapting opponent. Directly transfers, and no
     game-industry speaker will have this angle.
   - **"Verifying what your gacha actually does"** — implemented stochastic systems against
     disclosed probabilities, under the JOGA/CESA guidelines and 景表法.

A talk is the missing track record, a credential Japanese studios recognise, and direct access
to the buyer audience, obtained by writing well rather than by selling. If this fails twice,
that is real evidence the project has no entry.
